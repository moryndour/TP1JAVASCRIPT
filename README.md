# TP1 · Fondamentaux JavaScript

Travaux pratiques de JavaScript :
cinq exercices pour pratiquer les bases du langage sur un cas concret, la gestion de notes et de fiches d'étudiants.

## Objectif

Maîtriser les fondamentaux de JavaScript avant de passer aux frameworks : fonctions, objets, tableaux
et manipulation de données sans modifier les originaux.

## Contenu

| Exercice | Notions travaillées | Exemples |
|---|---|---|
| 1 | Fonctions, paramètres par défaut, fonctions fléchées | `CalculerMoyenne`, `EstAdmis`, `calculerPrixTTC`, `convertirEnMinutes` |
| 2 | Objets, déstructuration avec renommage et valeurs par défaut | fiche `etudiant` |
| 3 | Tableaux, décomposition (*spread*), copie d'objets | `groupeA`, `groupeB`, `etudiantComplet` |
| 4 | Paramètres du reste, déstructuration de tableaux | `additionner`, `afficherPremierEtAutres`, `creerFiche` |
| 5 | Synthèse : manipuler une fiche sans modifier l'original | `extraireIdentite`, `calculerMoyenneNotes`, `ajouterNote`, `creerResume` |

## Lancer le code

```bash
git clone https://github.com/moryndour/TP1JAVASCRIPT.git
cd TP1JAVASCRIPT
node tp1-javascript.js
```

Les résultats s'affichent dans la console.

## Technologies

JavaScript (ES6+), Node.js pour l'exécution.
